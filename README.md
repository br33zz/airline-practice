# Система управления авиакомпанией

Flutter Web-приложение для управления рейсами, самолётами, пилотами, услугами и пассажирами. В ПР4 локальное хранилище заменено на REST API с серверным поиском, фильтрацией, сортировкой и пагинацией.

## Запуск

В первом терминале:

```powershell
node api/mock-server.js --port 8080 --origin http://localhost:5555
```

Во втором терминале:

```powershell
flutter pub get
flutter run -d chrome --web-port=5555 --dart-define=API_BASE_URL=http://localhost:8080/api
```

Проверка сервера: <http://localhost:8080/api/__health>.

## Реализовано

- полный CRUD через API для пяти сущностей;
- логическое и физическое удаление, восстановление и множественное удаление;
- собственные исключения сетевого слоя без упоминаний Dio в виджетах;
- обработка 401, 403, 404, 409, 422 и 5xx;
- вывод ошибок 422 возле полей номера рейса и почты пассажира;
- серверные поиск, фильтрация, сортировка и пагинация;
- отмена устаревшего поискового запроса через `CancelToken`;
- до трёх попыток чтения при сетевом сбое с растущей паузой;
- однократное кэширование справочников самолётов, пилотов и услуг;
- блокировка кнопки формы во время сохранения;
- журналирование метода, адреса и кода ответа в режиме отладки;
- состояния загрузки, данных, пустого результата и ошибки с кнопкой повтора.

## Демонстрационные режимы

Задержка запросов для проверки индикатора загрузки:

```powershell
flutter run -d chrome --web-port=5555 --dart-define=API_DEMO_DELAY=1500
```

Принудительная ошибка 500:

```powershell
flutter run -d chrome --web-port=5555 --dart-define=API_DEMO_FAIL=500
```

## Проверка

```powershell
flutter analyze
flutter test
flutter build web
```

На Windows сборку следует выполнять из пути без кириллицы: компилятор шейдеров Flutter не умеет записывать часть ресурсов в каталог с русскими буквами.
