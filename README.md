# Практическая работа 2 — «Авиакомпания»

Flutter Web-приложение со списками рейсов и пассажиров. Реализованы Provider, go_router, слои models/repositories/state/screens/widgets, поиск с задержкой, фильтры, сортировка, пагинация, массовое и два вида удаления, восстановление, URL-параметры и адаптивная таблица/карточки.

## Запуск

```bash
flutter pub get
flutter run -d chrome
```

## Проверка

```bash
flutter analyze
```

## Ошибка в deleteMany

В исходном примере внутри `indexWhere` использовалось обращение `b[i].isDeleted`, хотя `b` — один объект, а `i` ещё не найден. В проекте условие исправлено на проверку текущего элемента: `x.id == id && !x.isDeleted`.

## Слои и общий виджет

- `models` — модели рейса, пассажира, запроса и страницы;
- `repositories` — источник данных и операции над ними;
- `state` — состояние экранов и уведомление интерфейса;
- `screens` — страницы списков;
- `widgets` — обобщённая таблица `EntityTable<T>`.

Общая таблица исключает дублирование сортировки, выбора строк, адаптивного представления и кнопок действий для рейсов и пассажиров.
